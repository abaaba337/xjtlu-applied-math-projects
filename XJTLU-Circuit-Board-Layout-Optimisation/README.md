# XJTLU Circuit Board Layout Optimisation

本科数学建模项目：将线路间交叉与线路自身转折表示成约束，把线路分配到尽可能少的电子线路板上。完整模型、图示、实验与 MATLAB 附录见 [研究报告](report.pdf)《基于 0-1 规划和贪心算法的电子线路板布线优化模型》。

## 模型与代码

[board_layout.py](board_layout.py) 根据报告附录第 23–26 页整理为 Python 可运行实现。输入是对称排斥矩阵 `intersections`：`R[i][j]` 表示两条线路的交叉数，主对角线为零；`turns[i]` 是线路自身转折数。某块板上的每条线路必须满足：

`自身转折数 + 与同板其他线路的交叉数之和 <= limit`

按总交叉数从小到大尝试添加线路，平局按编号排序，每次同时检查新线路和已入板线路，直到需要开启下一块板。输出线路编号从 1 开始。算法返回满足约束的贪心解，未提供全局最优性证明。

## 直接运行

只需 Python 3 标准库，无第三方依赖。在本目录运行：

```sh
python board_layout.py
python -m unittest -v
```

[report_cases.json](report_cases.json) 录入报告的三组十线路算例，分别是无交叉、允许一次交叉，以及交叉加转折约束。可复算得到 **3、2、3 块板**，测试同时检查每条线路恰好分配一次、每块板内所有约束成立，以及非法矩阵和不可行单线路被拒绝。

自定义输入可参照 JSON 文件，用 `python board_layout.py input.json` 运行。顶层对象按名称组织多个算例，每个算例包含 `intersections`、`limit` 和可选的 `turns`。

## 完整度

报告和附录完整保留，Python 部分是后续整理的算法复现。当前程序接收排斥矩阵，不从几何坐标自动寻路，也没有恢复报告中全部 18×18 布线案例、0-1 求解器流程或绘图工具。补齐对应矩阵与几何输入后才能验证这些部分；现有三组结果不代表所有报告结果均已复现。
